Setup on this computer
  1. Windows: Settings → Network & Internet → Proxy → Manual setup → paste the HTTP proxy.
  2. macOS: System Settings → Network → Details → Proxies → Web Proxy (HTTP) and Secure Web Proxy.
  3. Linux: export https_proxy=http://127.0.0.1:8085
  4. Firefox: Settings → Network Settings → Automatic proxy configuration URL → paste the PAC URL.
Setup on a phone (same Wi-Fi)
  1. Start with wififree serve --lan --auth user:pass.
  2. iOS: Wi-Fi → (i) → Configure Proxy → Manual → paste the HTTP proxy.
  3. Android: Wi-Fi → long-press network → Modify → Advanced → Proxy → Manual.
  4. Enter the username and password from --auth if prompted.

    How this gets around Wi-Fi restrictions

    1. Encrypted DNS

    DNS is sent over HTTPS to Cloudflare, Google and Quad9 at the same time, so a blocked or lying DNS server on the network cannot redirect you. Whichever answers first wins.

    2. One proxy, every protocol

    The same port speaks HTTP proxy and HTTPS CONNECT; port 1080 speaks SOCKS5. That covers browsers, apps and phones, including WebSockets and streaming.

    3. Fast built-in browser

    Pages are fetched server-side, decompressed while streaming and rewritten on the fly, then rendered with a slim toolbar. Assets pass through unchanged, so browsing stays snappy even on weak Wi-Fi.

    Only use this on networks you are allowed to use. Captive-portal probes are always kept direct, so the Wi-Fi sign-in page still works.
